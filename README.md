## 👨‍💻 About Me

Hey! I'm **Vansh Baghel**, a technology enthusiast passionate about cybersecurity, ethical hacking, software engineering, and building technology that makes the digital world safer.

I explore how systems work, how vulnerabilities arise, and how developers and security professionals can prevent, detect, and respond to cyber threats.

* 🔐 **Cybersecurity:** Learning security fundamentals, threat modeling, vulnerability assessment, and defensive security.
* 🕵️ **Ethical Hacking:** Exploring authorized security testing in labs and controlled environments.
* 🛡️ **Blue Team & Defense:** Interested in security monitoring, incident response, and threat detection.
* 🧠 **AI & Security:** Exploring machine learning, automation, and intelligent security tools.
* 💻 **Secure Development:** Building applications with security, privacy, and reliability in mind.
* 🌐 **Open Source:** Exploring projects, contributing to communities, and sharing knowledge.
* 🚀 **Innovation:** Building projects that combine software, security, and real-world impact.

> **My mission:** Learn continuously. Build responsibly. Protect what matters.
